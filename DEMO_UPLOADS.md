# Загрузка демо

1. Создайте матч в админке турнира.
2. Загрузите файл через `POST /api/server/demos`: Bearer API-ключ, multipart-поля `tournament_id` и `demo`.
3. Нажмите «Обновить список демо», выберите файл у нужного матча и нажмите «Привязать демо».

API загрузки возвращает HTTP 202, `match_id: null`, `status: pending`. Загрузка не создаёт матч и не запускает расчёт рейтинга.

Список непривязанных файлов: `GET /api/tournaments/:tournamentId/demos` (администратор).
Привязка и запуск обработки: `POST /api/matches/:matchId/demo/attach`, JSON `{ "demo_id": "UUID" }` (администратор).
Файл должен принадлежать турниру матча и ещё не быть привязанным.

Перед запуском обновлённого backend примените миграции: из `backend` выполните `npm run migrate`. Миграция `006_unassigned_demos.sql` разрешает хранить демо без матча и добавляет принадлежность турниру. Ранее созданные матчи сохраняются.
