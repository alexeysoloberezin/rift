# Загрузка демо

## Скриншот → CSV

Пришлите скрин таблицы статистики и полные ники обрезанных строк. Для импорта используется CSV с `source=screenshot` и колонками `team,name,steamid64,kills,deaths,assists,adr,head_shot_kills,source_rating,enemy5ks,enemy4ks,enemy3ks,enemy2ks,mvps`.
Steam ID можно оставить пустым: полный ник должен однозначно совпадать с зарегистрированным игроком этого турнира. Неизвестный/обрезанный ник вызывает ошибку, новый игрок по нему не создаётся. Ники должны соответствовать RIFT, а не угадываться по аватару или рейтингу.
ADR сохраняется со скрина. Точный суммарный урон, KAST и количество раундов по округлённым значениям не восстанавливаются. `source_rating` отображается как «Рейтинг скрина», отдельно от рейтинга RIFT, и не влияет на Elo. Неизвестные значения оставляются пустыми. Импорт использует ту же кнопку «Загрузить .dem / .csv». Перед использованием примените миграцию `009_screenshot_csv.sql`.

Поддерживаются `.dem` и CSV формата `match_data_mapN_ID.csv` (до 10 МБ). CSV можно загрузить у матча кнопкой «Загрузить .dem / .csv» или через тот же серверный API с полем `demo`.
CSV содержит статистику игроков: зрители исключаются, две команды определяются по колонке `team`, сторона A соответствует первой играющей команде файла (при совпадении капитанов используются команды турнира). Steam ID сохраняются без потери точности.
В таком экспорте нет карты, счёта, количества раундов и KAST. Карту и счёт задайте кнопкой «Карта и счёт». ADR, KAST и рейтинг остаются недоступными; Elo и его история не меняются. CSV не заменяет статистику уже оценённого матча. Для полного расчёта рейтинга можно позднее загрузить `.dem`.
Перед использованием CSV примените миграцию `008_csv_statistics.sql` обычной командой `npm run migrate`.

1. Создайте матч в админке турнира.
2. Загрузите файл через `POST /api/server/demos`: Bearer API-ключ, multipart-поля `tournament_id` и `demo`.
3. Нажмите «Обновить список демо», выберите файл у нужного матча и нажмите «Привязать демо».

API загрузки возвращает HTTP 202, `match_id: null`, `status: pending`. Загрузка не создаёт матч и не запускает расчёт рейтинга.

Список непривязанных файлов: `GET /api/tournaments/:tournamentId/demos` (администратор).
Привязка и запуск обработки: `POST /api/matches/:matchId/demo/attach`, JSON `{ "demo_id": "UUID" }` (администратор).
Файл должен принадлежать турниру матча и ещё не быть привязанным.

Перед запуском обновлённого backend примените миграции: из `backend` выполните `npm run migrate`. Миграция `006_unassigned_demos.sql` разрешает хранить демо без матча и добавляет принадлежность турниру. Ранее созданные матчи сохраняются.
